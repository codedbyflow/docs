## Endpoint

<CodeGroup>

```http
POST /api/flow-api/charge
```

</CodeGroup>

Cria uma nova cobrança PIX e retorna o código PIX e QR Code para pagamento.

## Headers

| Header          | Tipo   | Obrigatório | Descrição                    |
| --------------- | ------ | ----------- | ---------------------------- |
| `Authorization` | string | Sim         | Bearer token de autenticação |
| `Content-Type`  | string | Sim         | application/json             |

## Body Parameters

<ParamField body="value" type="number" required>
  Valor do pagamento em reais (ex: `1.00` = R$ 1,00). Valor mínimo: R$ 0,01
</ParamField>

<ParamField body="description" type="string">
  Descrição do pagamento (opcional)
</ParamField>

<ParamField body="expiresIn" type="number">
  Tempo de expiração em segundos (padrão: 3600 = 1 hora). Tempo mínimo: 60 segundos.
</ParamField>

<ParamField body="customer" type="object">
  Dados do cliente (opcional)
</ParamField>

<ParamField body="customer.name" type="string">
  Nome do cliente
</ParamField>

<ParamField body="customer.email" type="string">
  Email do cliente
</ParamField>

<ParamField body="customer.phone" type="string">
  Telefone do cliente (formato: +5511999999999)
</ParamField>

## Campos da Resposta

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `charge.id` | string | ID único da charge (correlationID) - use este ID para verificar o status |
| `charge.value` | number | Valor do pagamento em reais |
| `charge.status` | string | Status da charge (`ACTIVE`, `PAID`, `EXPIRED`, `CANCELLED`) |
| `charge.pixCode` | string | Código PIX copia e cola (texto) |
| `charge.pixCodeBase64` | string | Código PIX em base64 |
| `charge.qrCode.emv` | string | Código PIX EMV (mesmo que pixCode) |
| `charge.qrCode.image` | string | Imagem do QR Code em base64 (data URI) |
| `charge.publicPaymentUrl` | string | Link público para página de pagamento (pode ser compartilhado com clientes) |
| `charge.expiresAt` | string | Data/hora de expiração (ISO 8601) |
| `charge.createdAt` | string | Data/hora de criação (ISO 8601) |

<Note>
  O campo `charge.id` é o correlationID. Use este ID para verificar o status do pagamento usando o endpoint de verificação.
</Note>

### Node.js (Express)

```javascript

    const response = await fetch('https://flowapplications.com.br/api/flow-api/charge', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${process.env.FLOW_API_KEY}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({

        description: descricao,
        expiresIn: 3600

    })
    
    if (!response.ok) {
      throw new Error('Erro ao criar pagamento')
    }
    
    const data = await response.json()
    res.json(data)
  } catch (error) {
    res.status(500).json({ error: error.message })
  }
})
```

## Fluxo Completo de Integração

### 1. Criar o Pagamento

```javascript
// Criar charge
const createResponse = await fetch('https://flowapplications.com.br/api/flow-api/charge', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sua_api_key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    value: 10.00,
    description: 'Pagamento de produto X',
    expiresIn: 3600
  })
})

const { charge } = await createResponse.json()
const chargeId = charge.id
const pixCode = charge.pixCode
const qrCodeImage = charge.qrCode.image
const publicPaymentUrl = charge.publicPaymentUrl // Link público para compartilhar
```

### 2. Exibir QR Code ou Link Público para o Cliente

```javascript
// Opção 1: Exibir QR Code na interface
const qrCodeImg = document.createElement('img')
qrCodeImg.src = qrCodeImage
document.body.appendChild(qrCodeImg)

// Opção 2: Copiar código PIX
navigator.clipboard.writeText(pixCode)

// Opção 3: Compartilhar link público (recomendado)
// O link leva para uma página completa com QR Code, código PIX e verificação automática
window.location.href = publicPaymentUrl
// Ou compartilhar via WhatsApp, email, etc.
```

### 3. Processamento Automático

O pagamento será processado automaticamente quando confirmado. O saldo será adicionado à carteira do usuário associado à API key.

### Exemplo de Teste com Python

```python
# teste_pagamento.py
import requests
import json

def testar_criar_pagamento():
    url = 'https://flowapplications.com.br/api/flow-api/charge'
    headers = {
        'Authorization': 'Bearer flow_PnoJ4RIjN2Qs6yre1S87blyI3qqGlERvMQX1njoAkl0=',
        'Content-Type': 'application/json'
    }
    payload = {
        'value': 1.00,
        'description': 'Teste de pagamento',
        'expiresIn': 3600
    }
    
    try:
        response = requests.post(url, json=payload, headers=headers)
        data = response.json()
        
        if response.status_code == 200:
            print('✅ Pagamento criado com sucesso!')
            print(f'ID da Charge: {data["charge"]["id"]}')
            print(f'QR Code (base64): {data["charge"]["qrCode"]["image"][:50]}...')
            print(f'Link Público: {data["charge"]["publicPaymentUrl"]}')
            return data
        else:
            print(f'❌ Erro: {data.get("error", "Erro desconhecido")}')
            return None
    except Exception as e:
        print(f'❌ Erro na requisição: {str(e)}')
        return None

# Executar teste
if __name__ == '__main__':
    testar_criar_pagamento()
```
