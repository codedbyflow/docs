## Endpoint

<CodeGroup>

```http
GET /api/flow-api/charge/{chargeId}
```

</CodeGroup>

Verifica o status atual de uma charge criada anteriormente.

## Headers

| Header | Tipo | Obrigatório | Descrição |
|--------|------|-------------|-----------|
| `Authorization` | string | Sim | Bearer token de autenticação |

## Path Parameters

<ParamField path="chargeId" type="string" required>
  ID da charge retornado ao criar o pagamento (campo `charge.id`)
</ParamField>

## Try It

<RequestExample>

```bash GET /api/flow-api/charge/{chargeId}
curl -X GET https://flowapplications.com.br/api/flow-api/charge/flow_123_1704067200000_abc123 \
```

## Status Possíveis

| Status | Descrição |
|--------|-----------|
| `ACTIVE` | Charge criada e aguardando pagamento |
| `PAID` | Pagamento confirmado |
| `CONFIRMED` | Pagamento confirmado (sinônimo de PAID) |
| `COMPLETED` | Pagamento completado (sinônimo de PAID) |
| `EXPIRED` | Charge expirada (não é mais possível pagar) |
| `CANCELLED` | Charge cancelada |

## Verificando se o Pagamento foi Confirmado

```javascript
const charge = data.charge
const status = charge.status || charge.paymentStatus
const pixStatus = charge.paymentMethods?.pix?.status || charge.pix?.status

const isPaid = 
  status === 'CONFIRMED' || 
  status === 'PAID' || 
  status === 'COMPLETED' || 
  pixStatus === 'PAID' || 
  pixStatus === 'CONFIRMED' || 
  pixStatus === 'COMPLETED'

if (isPaid) {
  console.log('✅ Pagamento confirmado!')
} else {
  console.log('⏳ Aguardando pagamento...')
}
```


</ResponseExample>

## Exemplos de Código

### JavaScript (Fetch)


### Verificação Periódica (Opcional)

```javascript
// Verificar status periodicamente (opcional)
const checkStatus = async () => {
  const response = await fetch(`https://flowapplications.com.br/api/flow-api/charge/${chargeId}`, {
    headers: {
      'Authorization': 'Bearer sua_api_key'
    }
  })
  
  const { charge } = await response.json()
  const isPaid = charge.status === 'PAID' || charge.status === 'CONFIRMED'
  
  if (isPaid) {
    console.log('✅ Pagamento confirmado!')
    // Atualizar interface, enviar email, etc.
  }
}

// Verificar a cada 5 segundos (opcional)
// Nota: O pagamento será processado automaticamente mesmo sem verificação manual
setInterval(checkStatus, 5000)
```

<Note>
  O pagamento será processado automaticamente quando confirmado. Não é necessário fazer polling manual se você não precisar de atualizações em tempo real.
</Note>
