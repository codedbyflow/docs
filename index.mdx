## Bem-vindo à Flow API

A Flow API permite criar e gerenciar pagamentos PIX através da integração com a Woovi. Quando um pagamento é confirmado, o saldo é automaticamente adicionado à carteira do usuário associado à API key utilizada.

## Início Rápido

1. **Obtenha sua API Key** no painel da Flow (seção de API Keys)
2. **Configure a autenticação** usando Bearer token no header `Authorization`
3. **Crie seu primeiro pagamento** usando o endpoint `POST /api/flow-api/charge`
4. **Verifique o status** com o endpoint `GET /api/flow-api/charge/{chargeId}`

<Note>
  Todas as requisições devem incluir o header `Authorization: Bearer <sua_api_key>`. O pagamento será processado automaticamente quando confirmado.
</Note>
